# Incident Report: Ransomware Attack
## Summary

A ransomware attack was detected on May 2, 2026, targeting an unknown number of systems within the organization's network. The attacker gained access to administrative accounts and began encrypting files, followed by the creation of a ransom note.

## Timeline

* 01:14:07 - FAILED LOGIN attempt from IP address 185.220.101.47
* 01:20:55 - SUCCESS LOGIN from same IP address
* 01:22:03 - Creation of file `invoice.docx` on fileserver
* 01:31:40 - RENAME operation on files report.xlsx, budget.xlsx, and patients.db (adding .locked extension)
* 01:31:50 - Creation of ransom note file READ_ME_TO_DECRYPT.txt

## Root Cause

The root cause is not explicitly stated in the evidence logs. Further analysis is required to determine how the attacker gained access to administrative accounts.

## MITRE ATT&CK Mapping

1. **Initial Access**: The attacker likely used a phishing campaign to gain access to an administrative account, as indicated by the successful login from IP address 185.220.101.47.
	* Tactic: Initial Access
	* Technique Name: Phishing for Credentials
	* Technique ID: T1566.001
2. **Execution**: The attacker executed a ransomware payload on compromised systems.
	* Tactic: Execution
	* Technique Name: DLL Side-Loading
	* Technique ID: T1055.003
